# 공항가자 Airport-Gaja

**공항가자**는 공항 이동 전부터 이동 중까지의 여정을 통합 관리하고 안내하는 **LLM 기반 공항 이동 어시스턴트 프로토타입**입니다.

이 프로젝트는 실제 API나 실시간 데이터를 사용하는 서비스가 아니라, 발표 및 시연을 위한 **mock data 기반 React 프로토타입**입니다. 사용자는 항공편 정보, 출발지, 짐, 동행 여부, 이동 선호 등을 바탕으로 인천공항까지의 이동 경로를 추천받고, 이동 중에는 사진 기반 환승 안내와 자연어 채팅형 도움을 받을 수 있습니다.

---

## 1. 프로젝트 개요

공항 이동은 단순한 길찾기가 아니라, 항공편 시간, 공항 도착 목표 시간, 지역 간 이동, 수도권 환승, 예매 여부, 수하물, 지연 가능성, 버스 배차, 도로 정체 등을 함께 고려해야 하는 복합적인 여정입니다.

공항가자는 이러한 이동 과정을 LLM 기반 인터페이스로 통합하여, 사용자가 여러 앱과 정보를 오가지 않고도 하나의 흐름 안에서 공항 이동을 준비하고 수행할 수 있도록 돕는 것을 목표로 합니다.

핵심 경험은 다음과 같습니다.

> 항공편과 출발지를 기반으로 공항 도착 목표 시간을 역산하고,
> 안정성을 우선으로 경로를 비교한 뒤,
> 사용자의 선호를 반영해 최적 경로를 추천하고,
> 이동 중에는 현재 단계에 맞는 사진 기반 안내와 자연어 대화를 제공한다.

---

## 2. 핵심 컨셉

공항가자는 **분리형 진입점**을 가지되, 내부 경험은 단순 챗봇이 아니라 사용자의 자연어 입력을 바탕으로 전체 공항 이동 여정을 설계하는 **일체형 LLM 경험**으로 설계되었습니다.

### 서비스 정의

공항 이동 전부터 이동 중까지의 여정을 통합 관리 및 안내해주는 개인 맞춤형 공항 이동 어시스턴트

### AI 페르소나

공항 여정 계획, 예매, 이동, 환승을 안전하게 보조하는 신뢰형 LLM 어시스턴트

### 핵심 원칙

* 사용자를 대신해 최종 선택하지 않는다.
* 경로별 장단점과 리스크를 설명한다.
* 불안을 줄이되 위험을 숨기지 않는다.
* 실시간 정보의 불확실성을 명확히 안내한다.
* 실패를 선언하지 않고 복구 가능한 플랜을 제시한다.
* 이동 중에는 현재 위치 기준으로 다음 행동을 선제적으로 안내한다.

## 4. 주요 기능

### 4.1 항공권 예매 완료 맥락 기반 진입

항공권 예매 완료 알림을 받은 사용자가 공항가자에 진입하는 흐름을 보여줍니다.

* 항공권 예매 완료 알림
* 공항가자 진입 CTA
* 항공편 정보 확인
* AI 이용 안내

### 4.2 여정 조건 입력

사용자는 터치형 온보딩과 자연어 입력을 통해 여정 조건을 입력합니다.

입력 조건 예시:

* 출발지
* 항공편
* 동행자 여부
* 교통약자 여부
* 수하물 개수
* 수도권 환승 익숙도
* 이동 선호

### 4.3 안정성 우선 경로 추천

공항가자는 단순히 빠른 경로를 추천하지 않습니다. 먼저 실패 가능성이 높은 경로를 제외한 뒤, 남은 안정권 경로 안에서 사용자 선호를 반영합니다.

경로 추천 우선순위:

```text
안정성 > 사용자 선호
```

안정성 판단 기준:

* 운행 안정성
* 탑승 확실성
* 시간 완충성
* 환승 수행 안정성
* 대체 경로 확보 가능성
* 외부 변수 민감도

### 4.4 경로 비교 카드

사용자에게 2~3개의 핵심 경로를 카드 형태로 제시합니다.

각 경로 카드에는 다음 정보가 포함됩니다.

* 경로명
* 경로 요약
* 안정성 등급
* 예상 소요시간
* 예상 요금
* 환승 수
* 추천 이유
* 주의할 점
* 경로 선택 CTA

### 4.5 자연어 채팅 기반 후속 질문

사용자는 경로 카드 내부 버튼이 아니라 하단 채팅 입력창을 통해 자연어로 질문할 수 있습니다.

예시 질문:

```text
도로 정체가 걱정돼.
버스를 놓치면 어떻게 해?
짐이 많아도 괜찮아?
환승이 적은 대안 있어?
공항에 너무 일찍 가긴 싫어.
```

AI는 질문에 따라 경로 조건을 재해석하고, 필요한 경우 대안 경로 또는 복구 플랜을 제시합니다.

### 4.6 이동 중 사진 기반 환승 안내

사용자가 광명역 도착 30분 전, 공항가자는 다음 환승 동선을 사진과 함께 단계별로 안내합니다.

안내 단계:

1. 광명역 플랫폼에서 10호차 위치 찾기
2. 엘리베이터 탑승 후 1층 이동
3. 탐앤탐스 카페 기준 왼쪽 방향 이동
4. 4번 출구로 나가 6770 공항버스 정류장 찾기
5. 6770번 공항버스 확인
6. 캐리어 짐칸에 싣기
7. 인천공항 T2 3층 도착
8. 인천공항 T2 내부 체크인 안내

### 4.7 이동 중 자연어 대화

이동 중 화면 하단에는 메신저형 채팅 입력창이 고정되어 있습니다.

입력창 예시:

```text
공항가자에게 물어보기...
```

사용자는 이동 중 언제든 다음처럼 질문할 수 있습니다.

```text
지금 어디로 가야 해?
헷갈려요.
엘리베이터가 안 보여요.
버스를 놓쳤어요.
사진 다시 보여줘.
다음 단계가 뭐야?
```

공항가자 LLM은 현재 단계에 맞춰 상세하고 복구 중심의 안내를 제공합니다.

### 4.8 복구 플랜

사용자가 버스를 놓치거나 지연 상황을 입력하면, 공항가자는 실패를 선언하지 않고 가능한 대안을 제시합니다.

예시:

* 다음 6770번 버스 대기
* 6004번 공항버스 대안
* 택시 전환
* 기존 경로 유지 가능 여부 판단

## 6. 사용 이미지

본 프로젝트는 실제 시연 완성도를 높이기 위해 mock placeholder 이미지 대신 실제 시나리오에 맞는 이미지를 사용합니다.

이미지 파일은 `public/images` 폴더에 위치해야 합니다.

```text
public/
  images/
    항공권예매완료.png
    광명역플랫폼.png
    엘리베이터.png
    탐앤탐스.png
    공항버스정류장.png

    6770짐싣기.png
    인천공항터미널.png
    인천공항터미널내부.png
    아이콘.jpg
```

코드에서는 다음과 같은 경로로 이미지를 불러옵니다.

```js
const IMAGES = {
  ticket: "/images/항공권예매완료.png",
  platform: "/images/광명역플랫폼.png",
  elevator: "/images/엘리베이터.png",
  tomntoms: "/images/탐앤탐스.png",
  busStop: "/images/공항버스정류장.png",
  bus6770: "/images/6770버스.png",
  luggage: "/images/6770짐싣기.png",
  airportExterior: "/images/인천공항터미널.png",
  airportInterior: "/images/인천공항터미널내부.png",
  logo: "/images/아이콘.jpg",

```

이미지가 보이지 않는 경우, 파일명과 확장자가 코드와 정확히 일치하는지 확인해야 합니다.

## 14. 한계 및 유의사항

이 프로젝트는 발표 및 시연을 위한 프로토타입입니다.

따라서 다음 기능은 실제로 동작하지 않습니다.

* 실시간 항공편 조회
* 실시간 교통 정보 조회
* 실제 KTX/SRT 예매
* 실제 공항버스 예매
* 실제 결제
* 실제 지도 기반 길찾기
* 실제 LLM API 호출
* 실제 사용자 위치 추적

모든 데이터는 mock data이며, 실제 서비스 개발 시에는 관련 API 연동과 데이터 검증이 필요합니다.

## 16. 프로젝트 목적

본 프로젝트는 공항 이동이 익숙하지 않은 사용자의 불안을 줄이고, 복잡한 다구간 이동을 LLM 기반으로 구조화하는 사용자 경험을 검증하기 위한 프로토타입입니다.

특히 다음 질문에 대한 UX 가능성을 탐색합니다.

* LLM은 단순 상담 챗봇을 넘어 이동 여정을 설계할 수 있는가?
* 공항 이동에서 사용자는 어떤 기준으로 경로를 신뢰하는가?
